# airbnb-analysis
SQL-based local marketplace analysis using Inside Airbnb open data.

# Data

This project uses public data from Inside Airbnb.

Source:
https://insideairbnb.com/get-the-data/

Raw data files are not included in this repository due to file size.

Expected local files:

- data/raw/listings.csv
- data/raw/calendar.csv
- data/raw/reviews.csv
- data/raw/neighbourhoods.csv

Recommended city for the first analysis:
Tokyo, Japan
